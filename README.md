## The image

A one-page newspaper front page, drawn entirely in code:

- Masthead: THE WORLD TODAY, Wednesday 25 November 2026
- Top story: NATO vows to defend space, with a satellite over Earth
- Tariffs, climate summit, Shanghai chief under probe, Pacific security pact, and Shenzhou-24 lift off

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png`, a 1024 by 1024 PNG. Python 3.13, standard library only, no network. Two runs produce byte-identical output.
